# Scratchpad import — preserved source history

All 26 scratchpad files are captured here as text snapshots, including SVG source.
The sibling originals are retained unchanged. Further discussion and exploration
belong only in the lab under the user's latest instruction.

These are **historical records, not competing current contracts**. Old approval,
freeze, recording-location, and proposal labels describe their original checkpoints.
Files keep their original contents and source-relative links; use the index below
for navigation. The `.txt` suffix keeps historical examples distinct and makes
them available through the existing handbook asset pipeline without runtime edits.

In particular, Q-112A's proposed `parent_grant_revision` field was not adopted.
The assistant withdrew that proposal after the user reaffirmed lineage-supported
latest. See the [current Q-112/Q-112A clarification](../../direct-human-parent-context.md)
and [current revision rules](../../grant-revisions.md). Capturing a proposal here
is not approval of it or closure of support-discovery/conformance contracts.
